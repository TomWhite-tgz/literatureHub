§一句话结论

AgentScope 2.0 是一个"内核极薄、能力域极厚"的通用 agent 应用框架。
  • 它的内核只有 Agent(深 ReAct loop) + Middleware(七钩子) + Permission(五模式) + Toolkit(工具注册) 四件套，加起来不到 8000 行。
  • 它的"厚"全在能力域实现：FastAPI 服务层(2.8 万行)、沙箱后端(6 种)、工具系统(仿 Claude Code)、RAG、模型适配(8 家)。
  • 和科研 agent 谱系里的 InternAgent 对照，它的重量在单 agent 深度，InternAgent 的重量在多 agent 编排。两者抽象层相近，但哲学相反：AgentScope 让模型自己当 agent，InternAgent 让框架替模型编排。
  • 对科研用户的意义：如果你要搭一个"单 agent 跑很多轮、自己调工具、在沙箱里做实验"的系统，AgentScope 是比 InternAgent 更顺手的底座；反过来如果你要"多 agent 分工编排 + benchmark 跑分"，InternAgent 更对路。
