③ 会话与上下文：append-only 树，不是聊天数组

经典 coding-agent 的 v3 JSONL 同时承担恢复、分支、压缩、模型切换和扩展状态。

文件结构

第一行是 session header；后续 entry 通过短 id / parentId 形成树。当前 leaf 决定活跃分支。message 之外还有 model/thinking change、compaction、branch summary、custom、custom message、label 与 session info。

session header
  └─ model_change
      └─ thinking_level_change
          └─ user → assistant → toolResult
                         ├─ 原分支继续
                         └─ branch_summary → 新分支（current leaf）

custom 保存扩展状态但不进入模型上下文；custom_message 则明确参与 context。这个区分避免“要持久化”被错误等同于“每轮都喂给模型”。

证据：packages/coding-agent/docs/session-format.md；packages/coding-agent/src/core/session-manager.ts:418-504,1057-1160。

恢复 context 是一次投影

buildContextEntries() 从 leaf 向 root 找活跃路径，并处理最近 compaction；buildSessionContext() 再提取模型、thinking level 和可见 messages。新 compaction 可带物化的 retainedTail，因此 checkpoint 可自包含；旧格式则通过 firstKeptEntryId 回看历史，保证兼容。

entry进入 LLM context 的形式
message原 AgentMessage
compactioncompactionSummary + retainedTail（若有）
branch_summarybranchSummary message
custom_messageCustomMessage
custom / label / session_info不进入

压缩不是简单截断

自动触发条件是 contextTokens > contextWindow - reserveTokens。Pi 从尾部保留约 keepRecentTokens，优先按完整 user turn 切分；如果单 turn 本身过大，可以在 assistant message 处 split，但绝不从 tool result 处切断，因为 tool result 必须与 tool call 同组。

摘要使用固定结构保存 Goal、约束、进度、关键决策、下一步、关键上下文，并累计 read/modified files。序列化阶段会把 tool output 截至 2,000 字符，控制摘要请求本身的体积。

证据：packages/coding-agent/docs/compaction.md；packages/coding-agent/src/core/compaction/；packages/coding-agent/src/core/agent-session.ts:1786-2221。

overflow recovery 有界

当终态 assistant 被判定为 context overflow 或可恢复 length 时，AgentSession 先把失败 response 从 retry context 中移除，再执行 overflow compaction 并重试。每个 conversational input 只允许一次 compact-and-retry；再次 overflow 就显式失败，避免无限压缩循环。普通 threshold compaction 则发生在 turn 后，不必制造错误。

正确性细节：失败 response 已在 message_end 时持久化，恢复逻辑只从当前 agent context 中移除它；审计记录仍然存在。这比“为了重试而抹掉失败历史”更适合科研系统。

分支摘要保留“被离开的工作”

用户从 tree 的旧 leaf 导航到另一节点时，可对离开的路径做摘要。系统寻找共同祖先、收集 abandoned branch、生成 summary，然后在目标位置追加 branch_summary。因此新分支既不携带旧分支全部 token，也不会完全忘掉尝试过什么。

证据：packages/coding-agent/src/core/agent-session.ts:2899-3093；packages/coding-agent/src/core/session-manager.ts:1381-1450。

局限

  • v3 JSONL 写入与本进程 AgentSession 紧耦合，不是具备单 writer lease 的远程 durable runtime。
  • 经典 loop 的 tool execution 没有持久化 intent；进程在工具执行中崩溃时，不能仅靠 v3 transcript 判断是否安全重放。
  • 摘要保留的是模型生成的恢复信息，不能替代原始 artifact/evidence。
给 AutoResearch：复制“树 + projection + self-contained checkpoint”，但为实验工具再加 durable action intent/result、artifact hash、environment digest 和 replay policy；否则恢复对话不等于恢复实验。
