可以比较的系统

这里收录与 AutoResearch 有底层机制可比性的 Agent 系统。可比较不等于属于同一产品类别：本站先按类型分组，再做组内横向比较；跨组只讨论可迁移机制，不直接排功能高低。

当前分类与栏目

Coding Agent

直接接受代码仓库任务并完成读取、编辑、命令执行与交付的交互式 Agent 产品 / 运行时。

  • Codex (Rust) · Coding Agent：事件流内核、分层执行治理、平台沙箱与 app-server；第 ⑥ 页集中总结其优点及 AutoResearch 可借鉴部分。
  • Claude Code · Coding Agent：流式工具执行、权限来源、上下文减重、后台 Agent 与可恢复会话；第 ⑥ 页集中总结其优点及 AutoResearch 可借鉴部分。
  • Pi · Coding Agent：极小可嵌入 loop、消息投影、会话树与高自由度扩展；第 ⑥ 页集中总结其优点及 AutoResearch 可借鉴部分。
  • DeepSeek Harness · Coding Agent / Harness SDK：Cordis 插件树、事件溯源 loop、模型与工具治理、持久会话、subagent 与多前端；第 ⑥ 页以源码讲解 TypeScript，第 ⑦ 页专门对比 Pi。
  • Gemini CLI · Coding Agent：Scheduler、可归因 policy、多前端协议与声明式扩展；第 ⑥ 页集中总结其优点及 AutoResearch 可借鉴部分。
  • Grok Build · Coding Agent：SessionActor、批量工具治理、actor 化聊天状态、耐久会话与可重放 workflow；第 ⑥ 页集中总结其优点及 AutoResearch 可借鉴部分。

通用 Agent 开发框架

为开发者提供 Agent / 多智能体应用的运行时、组件与服务化能力，本身不是面向代码仓库交付的 coding agent。后续 AgentScope 同类系统应加入本组比较。

  • AgentScope · 通用 Agent 开发框架：包含 ReAct Agent、模型与工具接入、消息/记忆、工作区、服务化及多智能体应用组件。详见架构精读（源码版本 2.0.4.post1，分四部分）。

收录标准

优先收录有完整运行主链、能与 AutoResearch 做源码级机制映射的系统，例如：

  • 自身具有 Agent reasoning–acting loop；
  • 负责模型、工具和上下文/状态管理；
  • 能运行面向用户的完整任务；
  • 具有一定的可观测、权限、会话或部署能力。

LDP 侧重 policy、rollout、trajectory 与训练优化；AgentENV 侧重 microVM sandbox 基础设施。它们分别属于训练优化层和执行基础设施层，因此不放入上述两组直接比较。
