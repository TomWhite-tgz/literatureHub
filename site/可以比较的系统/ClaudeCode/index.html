先说结论

这份实现最鲜明的特征不是“会调用 Bash”，而是把 coding agent 当作一个持续流动、随时可恢复的并发会话：模型流到一半即可启动安全工具；每次 tool use 必须闭合成 result；权限由多种自动与人工来源竞态裁决；上下文不只做一次摘要，而是逐层减重；后台 agent 拥有独立 transcript、cwd 与生命周期。

一句话架构：QueryEngine / REPL 管会话，query() 驱动 agent loop，StreamingToolExecutor 在模型流下隐藏工具延迟，JSONL 的 parentUuid 图承担恢复与分支；Skills / Hooks / MCP / Plugins 则从四个方向扩展系统。
