⑤ 会话、前端与扩展：JSONL 图是恢复底座

Claude Code 在本地用 append-oriented transcript 保存事实，用 parentUuid 表达分支；同一 SDK message schema 又连接 stdio、remote 与 bridge。

Transcript 是事件日志，也是图

project-dir/session-id.jsonl
  message A {uuid, parentUuid:null}
    └─ message B {uuid, parentUuid:A}
       ├─ branch C ...
       └─ branch D ...   ← newest non-sidechain leaf → /resume 主链

project-dir/session-id/subagents/agent-<id>.jsonl
project-dir/session-id/subagents/agent-<id>.meta.json

loader 先读所有 message，计算“没有被其他 parentUuid 指向”的 leaves，再选最新非 sidechain leaf，沿 parent 链回溯。一个 JSONL 因而可以保留 rewind/branch 后的多条链，而不必覆盖原历史。旧版本误把 progress 放进链时，loader 还会桥接父指针以兼容恢复。

Compact boundary 的双父语义

写 compact boundary 时，物理 parentUuid 设为 null，让恢复无需再载入被摘要的全量前史；旧父节点保存在 logicalParentUuid，保留逻辑血缘。写入前 QueryEngine flush precompact tail，避免 crash 后边界先落盘、依赖消息仍在内存。

日志不是 UI dump。progress 明确被视为 ephemeral UI state，不参加 parent 链；assistant/user/compact boundary 才是恢复事实。这个分层阻止“展示事件”意外成为会话真相。
src/utils/sessionStorage.ts:1030-1067；src/QueryEngine.ts:687-730

写入模型

Project 为每个文件维护 write queue，定时批量 append，并提供 flush barrier。单条 user message 在进入 query 前被同步等待持久化；清理 handler 会先 flush，再把会话 metadata 重新追加到末尾，确保 resume picker 读取轻量首尾片段时拿到最新标题/模式。

源码还给 raw transcript 设置 50 MB 快速读取上限，因为现实 JSONL 可增长到 GB 级。这说明 append log 的优势（简单、可追溯）也带来索引与 compaction 成本。

四个扩展面各自解决不同问题

扩展单位关键安全/生命周期
SkillsSKILL.md 指令包managed/user/project/add-dir/plugin/MCP 来源；支持路径条件与动态发现；gitignored nested skill 被跳过
Hooks生命周期回调Pre/PostToolUse、PermissionRequest、UserPromptSubmit、SessionStart、SubagentStart/Stop、Stop；可阻断或修改输入
MCP外部 tool/resource/prompt server连接、OAuth、elicitation、server policy；agent 可有专属 server
