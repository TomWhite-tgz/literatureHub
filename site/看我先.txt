Literature · 自动化科研文献调研档案（分享站 · 持续更新）
==========================================================

【怎么看】
  双击 index.html，用浏览器打开即可。
  纯静态页面，不需要联网、不需要装任何东西。
  推荐 Chrome / Edge / Firefox。

【里面有什么】
  1. 选题讨论    —— agentic literature search 综述能否发顶会的完整分析
                    （四类做法：纯综述 / 统一复现 / 新 benchmark / benchmark+新方法，
                      各自要做什么、怎么实现、顶会潜力如何）
  2. 领域版图    —— 约 130 篇相关工作分八大类 + FutureHouse LABBench2 谱系
                    + 56 个自主科研系统按功能分类
  3. 项目与系统  —— 12 个系统的论文全文 + 源码深读评价，按可信度分三档：
                    复杂（真材实料）/ 简单（有实质但有限）/ 包装的好看（卖点不成立）
  4. 横向对比    —— PaSa / PaSaMaster / PaperPilot / PaperScout 四系统横向比较
  5. Benchmark   —— AstaBench、ScholarQuest、SPARBench、RollingEval 等精读
  6. 数据源      —— 21 个学术数据源能不能自己接、怎么接、限制在哪
  7. 商业产品    —— Elicit / Consensus / Ai2 Asta / Scite 等工具生态
  8. 我的思考    —— 调研笔记

  页面里的折叠块（带 ▸ 的标题）点一下会展开。

【关于论文和源码】
  为了控制体积（原始档案 107 GB），源码仓库和数据集没有打包。
  · 论文 PDF 已包含，页面里点击即可阅读
  · 精读页面里作为证据直接引用的源码片段（.py 文件）保留了，
    所以"某个卖点在代码第几行失守"这类结论可以点开核对
  · 详见包内的 _未包含的内容.html

【一句话结论（如果你只想看这个）】
  四个文献搜索系统深读后的定性：
    PaSa       复杂          真 RL 训练 + 真算法贡献，但 SOTA 要打七折看
    PaperScout 简单          论文里的 PSPO 就是 GSPO 改了个名，训练脚本写着 loss_mode=gspo
    PaperPilot 包装的好看    "归纳"=抄 36 份手调模板，训练代码 0 行，主表两行被外置 JSON 覆盖
    PaSaMaster 包装的好看    仓库 0 行代码，benchmark 用自家引擎构建，蹭名 PaSa 却不与 PaSa 比较

  共性问题：全部用自建 benchmark 且有不同程度循环性；"agent 自主性"多是叙事而非实现；
            后三篇活在 PaSa 的评测生态里但无一与 PaSa 公平正面比较；开放度与论文质量正相关。
