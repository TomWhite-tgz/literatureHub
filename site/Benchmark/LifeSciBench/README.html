数据集与代码的公开状态

截至核查日期，未发现 OpenAI 官方公开发布的 LifeSciBench 数据集、任务附件、rubric 或评测代码，因此这些内容目前无法下载。

核查依据：

  1. OpenAI 官方发布页只提供论文链接以及参与贡献、申请 GPT-Rosalind 访问的入口，没有数据集或代码入口。
  2. 论文附录 A.5（Data Availability and Safety Disclosure）明确指出：任务、rubric、artifact 或评测材料的公开发布可能因许可、隐私、专有信息或生物安全考虑而受到限制。
  3. GitHub 公开仓库搜索 LifeSciBench 未发现 OpenAI 官方仓库；精确名称搜索结果为 0。
  4. Hugging Face 数据集搜索 LifeSciBench 返回空列表；OpenAI 官方 Hugging Face 组织中也没有对应数据集。
  5. 论文 PDF 中没有嵌入 GitHub、Hugging Face、数据下载或代码仓库链接。
  6. 论文中未附可用于数据集或代码再分发的开源许可证。

这意味着论文中描述的以下完整 benchmark 内容尚未公开下载：

  • 750 个专家编写的任务；
  • 1,062 个配套 artifacts；
  • 19,020 条 rubric criteria；
  • 模型输出、逐任务评分及评测 harness。

本目录没有下载名称相似的第三方项目，因为它们不是论文作者发布的 LifeSciBench 数据或代码。
