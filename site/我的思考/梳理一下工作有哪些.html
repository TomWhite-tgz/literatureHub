Literature Agent、Deep Research 与论文处理相关工作

本文档只列举相关工作及其核心功能，不记录来源综述自身的分类、评分和研究结论。

一、文献检索、阅读与综述生成系统

工作 做什么
PaperQA2 / Language Agents Achieve Superhuman Synthesis of Scientific Knowledge（2024） 面向科学文献问答和知识综合，通过检索、证据抽取与引用绑定生成有来源支撑的回答。
OpenScholar（2024） 使用检索增强语言模型搜索科学文献并撰写带引用的研究综述。
ResearchAgent（2024） 在科学文献基础上迭代生成、扩展和改进研究想法。
Tree-of-Debate（2025） 使用多角色辩论树比较科学论文，围绕方法、证据和结论进行批判性分析。
OpenResearcher（2026） 开放的长程 Deep Research 轨迹生成管线，记录搜索、打开页面和文内查找等证据搜集步骤。
PaperScout（2026） 面向学术论文搜索的自主 Agent，优化多步检索过程和最终论文发现质量。
WebWatcher（2025） 结合网页视觉理解与长程搜索的多模态 Deep Research Agent。
WebAtlas（2025） 通过经验记忆和动作模拟完成长程网页检索与信息搜集。
Marco DeepResearch（2026） 采用 verification-centric 设计筛选问答合成数据、搜索轨迹和测试时答案。
Kosmos（2025） 联合执行文献检索与数据分析，并将报告中的陈述链接到文献或 notebook 证据。
AI-Researcher（2025） 将文献研究、数学到代码转换、实验执行和论文写作串成自动科研流程。
PhysMaster（2025） 面向理论与计算物理，结合文献/知识库检索、MCTS 推理和模拟器检查。
Parness（2026） 为自动科研提供动态 workflow、全文索引和跨运行知识积累。
BioDisco（2025） 结合文献与领域证据生成生物医学假设，并通过反馈和时间维度评测更新假设。
ReSearch（2026） 面向地球科学的数据发现，通过多阶段机器学习流程寻找和组织研究数据。
NanoResearch（2026） 让技能、记忆和策略共同演化，以支持个性化、长期运行的研究自动化。
HybridQuestion（2026） 通过人机协作识别和筛选高影响力研究问题。

二、包含 Literature 模块的端到端科研系统

工作 做什么
The AI Scientist（2024） 从研究想法、相关文献、实验和结果分析一直推进到论文撰写与自动评审。
The AI Scientist-v2（2025） 使用 Agentic Tree Search 搜索研究方向，并加入图表检查、实验迭代和论文生成。
Agent Laboratory（2025） 将文献综述、实验和报告写作组织为多阶段研究助手工作流。
Towards an AI Co-Scientist（2025） 从文献和领域知识中生成、辩论、排序和演化生物医学研究假设。
NovelSeek（2025） 构建从假设生成、文献/知识支持到计算验证的闭环发现系统。
AgentRxiv（2025） 支持多个研究 Agent 协作产出、共享和检索研究成果。
OmniScientist（2025） 组织人类与 AI 科学家共同进行构思、实验、写作和评审。
ARIS（2026） 使用对抗式多 Agent 协作覆盖研究构思、实验、论文写作、审计和 rebuttal。
NORA（2026） 面向空间数据科学的端到端研究 Agent，包含全文检索、论文写作、审查和提交检查。

三、Literature Discovery 与 Deep Research Benchmark

Benchmark 主要评测内容
BrowseComp（2025） 测试浏览 Agent 在开放网络中寻找难定位事实和组合证据的能力。
BrowseComp-Plus（2025） 提供更透明、可检查的 Deep Research Agent 浏览评测。
DeepResearch Bench（2025） 综合评测 Deep Research Agent 的检索、长报告生成、报告质量与引用可靠性。
DeepResearch Bench II（2026） 使用专家报告生成的细粒度 rubrics 诊断 Deep Research Agent 的具体能力缺口。
DeepResearchEval（2026） 自动构造 Deep Research 任务并对 Agent 搜索和报告结果进行评测。
DeepScholar-Bench（2025） Live Benchmark，重点评测 related-work 检索、引用正确性和研究综述综合质量。
AstaBench（2025） 以科学研究任务套件评测 Agent 的文献搜索、证据使用和研究推理能力。
AutoResearchBench（2026） 评测复杂科学文献发现，包括搜索、论文匹配、信息抽取和研究综合。
DEER（2025） 评测 Deep Research Agent 生成专家级长报告的能力。
DR³-Eval（2026） 使用静态任务 sandbox 对 Deep Research 报告进行现实、可复现的评测。
DeepWeb-Bench（2026） 要求 Agent 从大量跨来源网页中收集证据并完成长链推导。
MMDeepResearch-Bench（2026） 评测需要同时理解文本、图像等信息的多模态 Deep Research Agent。
ResearchBench（2025） 将科学发现拆解为寻找灵感、理解关联和形成研究方向等任务。
ResearchArena / How Far Are We from True Auto-Research?（2026） 通过自评、同伴评审和人工评审比较自动生成研究论文的质量。

四、Rubric 与报告评测

工作 做什么
ResearchRubrics（2025） 提供用于评价 Deep Research Agent 的任务、提示词和人工编写 rubrics。
OpenRubrics（2025） 自动生成可扩展的评测 rubrics，用于开放式回答和 reward modeling。
RubricBench（2026） 测量模型生成的 rubric 与人类标准之间的一致性。
ProfBench（2025） 使用需要专业领域知识的多领域 rubrics，同时测试回答和评判能力。
JudgmentBench（2026） 比较 rubric-based evaluation 与直接偏好判断在质量评估中的差异。
CriterAlign（2026） 将 judge 的判断依据与明确评价标准对齐，重点训练 criterion-centric rationale。
Deep Research, Shallow Evaluation（2026） 对长文本问答 Benchmark 做 meta-evaluation，检查当前 Deep Research 评价是否真的可靠。

五、引用、证据与论文错误 Benchmark

Benchmark / 工作 主要评测内容
Source or It Didn’t Happen / CiteTracer（2026） 使用多 Agent 和书目检索级联检测伪造、不可解析或与正文不匹配的引用。
SPOT（2025） 使用作者确认的真实论文错误评测自动科学研究验证能力。
FLAWS（2025） 评测模型发现并定位科学论文中错误的能力。
SciIntegrity-Bench（2026） 测试 AI Scientist 系统在引用、实验、结果和写作中的学术完整性风险。
SoundnessBench（2026） 判断 AI 科学家能否区分可靠与低 soundness 的研究想法。
Paper Reconstruction Evaluation / PaperRecon（2026） 通过论文重建任务评测 AI 论文的表达质量和 hallucination。
MLReplicate（2026） 让系统围绕既有 ML 论文生成复现稿件，并检查其复现性和 claim 支撑情况。
PaperBench（2025） 根据论文和代码从头复现 AI 研究，以细粒度作者 rubric 和实际执行评测。
SciReplicate-Bench（2025） 评测 Agent 从研究论文重新实现算法并执行复现实验的能力。
CORE-Bench（2024） 测试 Agent 对已发表计算研究进行可执行复现的能力。
Repro-Bench（2025） 评测 Agent 能否判断社会科学研究的计算可复现性。
ResearchCodeBench（2025） 评测模型根据论文描述实现新的机器学习研究代码。
NoveltyBench（2025） 评测语言模型生成研究想法时的多样性与人类式创新表现。
HindSight（2026） 通过后续真实影响反向评估自动生成研究想法的潜在价值。

六、论文审查、引用验证与可审计研究

工作 做什么
DeepReviewer 2.0（2026） 将审查意见锚定到 PDF 文本位置，检索比较论文，建立 claim–evidence–risk 记录并输出可追踪评审包。
ScholarPeer（2026） 使用上下文感知的多 Agent 协作完成自动同行评审。
Refute-or-Promote（2026） 使用对抗式、多阶段 gate 对论文缺陷进行高精度发现和复核。
From Fluent to Verifiable（2026） 为 Deep Research 输出定义 claim-level provenance、证据覆盖、矛盾透明度和审计成本。
ScientistOne（2026） 使用 Chain-of-Evidence 检查引用、数值、方法、代码与结论之间的对应关系。
AutoResearchClaw（2026） 在研究执行时记录数字和引用来源，并在论文生成阶段检查不匹配内容。
Evidence-Bound Autonomous Research / EviBound（2025） 以运行 ID、日志、artifact 和指标约束研究 claim，减少没有执行证据的结论。
LLM-REval（2025） 检验 LLM reviewer 的可靠性及其与可信评审标准之间的差距。
Can LLM Feedback Enhance Review Quality?（2025） 在真实 ICLR 评审流程中随机测试 LLM 反馈能否改善人类审稿质量。
When Your Reviewer Is an LLM（2025） 分析 LLM 同行评审中的偏差、判断分歧和 prompt injection 风险。
Are We There Yet? Risks of LLMs in Scholarly Peer Review（2024） 系统分析将 LLM 用于学术同行评审可能产生的可靠性和安全风险。
Prompt Injection Attacks on LLM-Generated Reviews（2025） 研究论文文本中的提示注入如何操纵自动审稿结果。
When Reject Turns into Accept（2025） 量化间接 prompt injection 将 LLM reviewer 的拒稿判断翻转为接收的风险。
All That Glitters Is Not Novel（2025） 研究 AI 生成论文中的抄袭、重述和虚假创新问题。
Time to Reflect: Can We Trust LLM Judges for Evidence-Based Research Agents?（2026） 检查 LLM judge 在需要真实证据支撑的研究 Agent 评测中是否可信。

七、将论文转换为 Agent 可用 Artifact

工作 做什么
Paper2Agent（2025） 将论文及其代码仓库转换为可交互、可调用的研究 Agent/MCP Server。
Executable Knowledge Graphs / xKG（2025） 将论文中的方法、代码和依赖关系转换为可执行知识图谱，服务于复现和下游 Agent。
Agent-Native Research Artifacts / ARA（2026） 将论文扩展为包含认知过程、物理 artifact、探索图和证据层的 Agent-native 研究包。
Knows（2026） 使用结构化 sidecar 表达 statements、evidence、artifacts、relations 和 actions。
Figures as Interfaces（2026） 将论文图表变成可查询对象，并关联渲染图、数据、代码和可视化规格。
Paper2Code（2025） 从机器学习论文自动生成对应研究代码。
Paper2Web（2025） 将静态科研论文转换为可交互网页。
Paper2Video（2025） 根据科研论文自动生成讲解视频。
HIRAS（2026） 使用分层多 Agent 从论文生成代码并执行验证。
What Papers Don’t Tell You（2026） 从论文及其相关材料中恢复没有明确写出的 tacit knowledge，帮助自动复现。
AutoReproduce（2025） 根据论文谱系组织自动实验复现，追踪方法与前序工作的关系。
Reflective Paper-to-Code Reproduction（2025） 通过细粒度验证与反思，把论文逐步转换为可运行代码。
From Paper to Benchmark（2026） 将描述不充分的论文方法转化为可执行 Benchmark，并进行静态、dry-run、泄漏和结果匹配检查。
