各渠道的可接入情况

数据源 能否自行接入 常见方式 主要限制
OpenAlex 可以，推荐 REST API、全量数据快照 元数据覆盖广，但摘要、作者消歧和引用数据并非绝对准确
Crossref 可以，推荐 REST API 主要是 DOI 元数据，不是论文全文库
Semantic Scholar 可以 Academic Graph API 有速率限制；部分能力可能需要 API Key
arXiv 可以 API、OAI-PMH、公开论文文件 需要控制请求频率；批量使用要遵守许可和服务规则
PubMed 可以 NCBI E-utilities PubMed 主要提供元数据和摘要，不等于全部全文
PubMed Central 部分可以 API、OAI、开放获取子集 只有符合许可的文章才能批量下载或再利用
Europe PMC 可以，生物医学推荐 REST API、开放全文接口 全文权限取决于文章许可
bioRxiv/medRxiv 可以 官方 API、预印本页面 预印本未必经过同行评审；PDF 再利用需看许可
Unpaywall 可以 DOI 查询 API、数据快照 它提供开放全文位置，不提供所有论文全文本身
OpenCitations 可以 REST API、开放数据集 引用覆盖不等于 Web of Science 或 Scopus 的完整覆盖
CORE 可以申请 API、开放仓储聚合 API 配额、全文使用条件需遵守其政策
Google Scholar 无官方公共 API 不建议直接爬虫 自动抓取容易触发封禁，也可能违反服务条款
Web of Science 有条件 商业 API 通常需要机构订阅或单独授权
Scopus 有条件 Elsevier API 需要注册，完整能力通常与订阅权限相关
Dimensions 有条件 API、DSL 一般需要许可证或机构合作
IEEE Xplore 有条件 官方 API 有配额、字段及全文权限限制
Springer Nature 有条件 官方 API 元数据、摘要和开放全文权限不同
ACM Digital Library 有限 授权数据、出版社合作 不适合作为无许可的批量抓取源
CNKI、万方、维普 通常有条件 机构接口、商业授权 不应默认通过网页爬虫批量抓取
专利数据库 因机构而异 专利局 API、批量数据 EPO、USPTO、WIPO 及各国专利局规则不同
普通公共网页 技术上部分可行 搜索接口、定向抓取 必须检查 robots、服务条款、版权和个人信息规定

一些Tips

  • API 返回论文，不代表可以保存全文
  • 检索元数据：标题、作者、摘要、DOI；
  • 去重
  • 定义搜索质量，来排序
