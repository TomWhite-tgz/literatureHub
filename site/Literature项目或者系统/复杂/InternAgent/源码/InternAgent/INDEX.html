InternAgent 导航索引 (for agents)

InternAgent-1.5：一个端到端「自主科学发现」agent 框架——给定一个科研任务(算法发现 / 论文复现)或一个研究问题(QA/深度调研)，由多 agent 系统自动完成 假设生成→方法设计→实验编码与运行→评估→报告/答案。覆盖 Physical / Biology / Earth / Life Science 等领域的算法发现与实证(干湿实验)发现。主语言 Python(占绝大多数)，多个入口脚本。上游 github.com/InternScience/InternAgent。当前副本为 main@b8a9e81；主仓库本体(不含子模块)实测约 58M、1288 个 .py 文件——其中 405 个在 internagent/mas/agents/dr_agents/(即内嵌的 FlowSearch 深度调研子系统，基于 CAMEL)，整个 internagent/mas 共 459 个 .py。sci_tasks/ 已按主仓库锁定的 ResearchClawBench@9b5288e 完整检出。

科研流程 / 控制流

Discovery / sci_task 模式(launch_discovery.py:main)：
1. argparse → detect_task_type(有 task_info.json 为 sci，否则 auto)；sci 任务用 normalize_sci_task 合成 prompt.json。
2. 进入 loop_rounds 循环(config workflow.loop_rounds)。每轮：
- 想法生成：internagent/stage.py:IdeaGenerator.generate_ideas() → internagent/mas/interface.py:InternAgentInterface → internagent/mas/workflow/orchestration_agent.py:OrchestrationAgent 跑状态机：GENERATING→REFLECTING→EVOLVING→METHOD_DEVELOPMENT→REFINING→RANKING(各 _run_*_phase 调对应 agent 的 execute()，agent 内部用 BaseAgent._call_model* 经 OpenAIModel→OpenAI 兼容 API)。产出 top ideas → ideas.json。
- 实验执行(--mode experiment)：ExperimentRunner.run_experiments → setup_*_experiment_folder 建工作区 → 按 self.backend dispatch：run_claude_experiment(→experiments_utils_claude.perform_experiments，shell 调 claude CLI 真正写代码/跑实验/迭代调试) / run_iflow_experiment / run_openhands_experiment；use_mcts=true 时走 mcts_experiments_utils_*。GPU 由 GPUAllocator 分配，最多 max_parallel_experiments 并行。
- 记忆更新：在线记忆自动保存最佳结果(online_memory)，长程记忆 IdeaGraph + PromptEvolver 演化下一轮 prompt。
- --mode report 分支：跳过实验，ReportWriter.generate_reports 出 markdown。
3. sci_task 评分：sci_task.scorer_model(LLM-as-judge) 按 checklist.json 给报告打分，评估代码经 internagent/rcb_evaluation(→sci_tasks/evaluation)。

QA 模式(launch_qa.py)：DRAgent(model='o4-mini', mode='qa').execute({task, file_path}) → 懒加载 internagent/mas/agents/dr_agents/(FlowSearch / CAMEL) 的 Workflow，按 config_qa.yaml 把问题拆子任务、并行检索学术库+web、合成答案。无实验循环。

  • agent 定义/注册：类继承 BaseAgent(internagent/mas/agents/base_agent.py)，实现 async def execute(self, context, params)；注册靠 agent_factory.py:_agent_registry(静态 dict，非装饰器) + config_default.yaml:agents.<type>。grep：_agent_registry、class .*Agent\(BaseAgent\)、register_agent_type。
  • 阶段(phase)定义：grep WorkflowState(枚举见 workflow/data_type.py)、phase_handlers、_run_.*_phase(均在 orchestration_agent.py)。
  • 工具定义/注册：function tool = (OpenAI 风格 *_TOOL_DEFINITION dict + 函数)，在 tools/__init__.py:init_tools() 里 register_tool(...)。grep：register_tool、TOOL_DEFINITION、get_registry、ToolRegistry。
  • LLM provider 定义：model_factory.py:MODEL_PROVIDER_MAP(provider→module.Class 字符串)；client 类在 internagent/mas/models/*_model.py。新增 provider：加进 map 或调 ModelFactory.register_model。grep：MODEL_PROVIDER_MAP、AsyncOpenAI、provider。
  • 实验后端：grep exp_backend、perform_experiments、ClaudeCodeRunner、run_.*_experiment(stage.py + experiments_utils_*.py)。
  • prompt 模板位置：discovery internagent/prompts.py(常量 *_PROMPT)；agent 内联 prompt 在各 agents/*.py(grep PROMPT/system_prompt)；DR 在 dr_agents/prompts/、dr_agents/camel/prompts/、dr_agents/utils/prompt_loader.py。
  • config→运行行为映射：config/default_config.yaml 经 InternAgentInterface._load_config 读入 → agents: 驱动哪些 agent 被建及其参数；workflow.loop_rounds/max_iterations/top_ideas_count 控制循环；experiment.model/use_mcts/max_parallel_experiments/gpu_per_experiment 控制实验；models.default_provider 选 LLM；sci_tools.remote 列出 MCP server；memory.* 开关四种记忆。
  • 环境变量/密钥：.env(从 .env.example)。默认 OpenAI 路径使用 OPENAI_API_KEY+OPENAI_API_BASE_URL；OpenRouter provider 使用 OPENROUTER_API_KEY+OPENROUTER_BASE_URL(见 docs/openrouter.md)；ANTHROPIC_API_KEY供 claudecode 后端调用本机 claude CLI。其他可选项包括 OPENAI_BASE_URL(sci_task scorer 别名)、GEMINI_*/DS_*/INS1_*、VOLC_SEARCH_API_KEY/TAVILY_API_KEY/SERPER_API_KEY/S2_API_KEY、HF_TOKEN/MODELSCOPE_SDK_TOKEN。

Gotchas

  • 主库 + 大型子模块：主仓库 1288 个 .py 里 405 个是 dr_agents/(内嵌 FlowSearch，含整份 camel/ 框架)——改 discovery 主流程通常不需要碰它；它只服务 QA/深度调研与 generation 阶段的背景调研。
  • sci_tasks/ 已固定版本检出：.gitmodules 指向 ResearchClawBench，当前检出主仓库锁定的 9b5288e。不要随意切到子模块自己的最新 main，否则可能偏离 InternAgent 测试过的依赖状态。
  • 两套"模型"概念别混：(a) MAS 推理用的 LLM = OpenAI 兼容 client(OPENAI_API_BASE_URL，默认 gpt-4o/QA 用 o4-mini)；(b) 实验后端 claudecode 是直接 shell 调用本机 claude CLI(experiments_utils_claude.py，需装好 Claude Code 且 ANTHROPIC_API_KEY)，不是用 Anthropic SDK。iflow/openhands 是另两种后端。
  • --exp_backend 在 experiment 模式必填(choices: openhands/claudecode/iflow)；首跑建议 --task AutoDebug(自包含合成数据，~5s/run，无需下载)。
  • GPU 依赖：internagent/utils.py 与 stage.py:GPUAllocator 直接 import torch 并按 CUDA 设备分配；无 GPU 环境跑算法发现任务可能受限(toy 任务 AutoDebug 可在 CPU 跑)。
  • MCP 有两套 manager：mcp_manager.py 与 mcp_manager_fastmcp.py(FastMCP 2.0，自动探测 stdio/SSE/HTTP)；远程 server 在 config:sci_tools.remote 配 url/headers，本地 server 走 stdio(样例 tools/mcp/demo_server.py)。
  • 离线记忆是手动步骤：训练/运行不会自动灌历史，需跑 add_offline_mem.py 把 traj_session_*.json 导入 ./config/mem_store；在线记忆(运行时自动存最佳结果)与之不同。
  • 多入口转发：launch.py 用 parse_known_args 剥掉 --mode 后把剩余 argv 交给 launch_qa.main/launch_discovery.main——加新 CLI 参数要加到具体子入口而非 launch.py。
  • sci_tasks.scorer_model/QA 默认模型写死了具体型号(如 gpt-5.1、o4-mini、claude-sonnet-4-5-20250929)，换端点时注意你的 base_url 是否支持这些模型名。
