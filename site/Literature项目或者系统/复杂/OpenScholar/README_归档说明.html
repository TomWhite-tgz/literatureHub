OpenScholar 归档说明

  • Nature：https://doi.org/10.1038/s41586-025-10072-4

目录内容

中文导读

  • OpenScholar_系统架构与论文精读.html：综合论文、补充材料、官方代码与 ScholarQABench 的中文深度导读，包含系统流程、实验解读、源码审计和复现边界。
  • assets/：导读页面使用的本地论文图表，页面无需联网即可显示。

paper/

  • OpenScholar_Nature_2026.pdf：Nature 正式版本。
  • OpenScholar_Nature_2026_Supplementary_Information.pdf：Nature 补充材料。
  • OpenScholar_Nature_article_page.html：Nature 文章页面离线副本。
  • OpenScholar_arXiv_2411.14199.pdf：arXiv 版本。
  • OpenScholar_arXiv_2411.14199_source.tar.gz：arXiv 原始源码包。
  • arxiv_source/：解压后的 LaTeX、参考文献、图表与图片。

code/

  • OpenScholar/：官方主代码仓库，包含推理、训练和检索代码。
  • 归档提交：0e9b8fb912273d3dae39e593da86e4f6d3bf8de1（2025-08-12）。

benchmark/

  • ScholarQABench/：官方 benchmark、问题、专家答案、rubric、预测结果和评测代码。
  • 归档提交：95e6fc52b0a8a0ce0a74956029991e3bb00c38b9（2025-08-12）。

evaluation/

  • OpenScholar_ExpertEval/：专家人工评测界面和评测结果。
  • 归档提交：ecf16c2e89bd7968a2605c30b6ff0812e2cfec31（2024-11-19）。

demo/

  • open-scholar-demo/：当前官方 README 指向的公开 Demo 代码。
  • openscilm/：论文代码可用性声明所用的旧仓库名；GitHub 当前会重定向到 open-scholar-demo。
  • 两个目录在归档时均解析到提交 565cfbb4e77fa520196631cc710147de2b9a4ca1（2026-04-06），内容等价。
