§与 InternAgent 的重量对照

用 InternAgent 精读里那张"6 层套娃"表，把 AgentScope 放进去对照，能看出两者的设计哲学分野：

层InternAgentAgentScope
① 一步 execute_call_model 一次性结构化 JSON_reasoning_impl 调模型，产出四类 Block
② 一次 react薄(仅 generation 用)厚(核心循环单元)
③ agent_loop薄(11 个 agent 仅 generation 用)厚(while cur_iter < max_iters 的深 loop)
④ 编排厚(重心)：状态机 + 11 个 agent 串行薄：Agent Team 只提供"建团队/发消息"原子操作
④.5 实验循环厚·外包：subprocess 调 claude CLI薄：不假定外包，由用户在 workspace 后端上自写
⑤ 演化厚(招牌)：loop_rounds + PromptEvolver无：不提供跨轮自演化原语
一句话总结两者的分野：
  • InternAgent 把"想"和"做"物理分离——想是浅 agent 串行编排，做是外包给 Claude Code。它同时是多 agent 科研编排框架和benchmark 跑分平台。
  • AgentScope 把重量全压在单 agent 的深 ReAct loop 上，编排只给"建团队/发消息"的薄原语。它是一个通用 agent 应用框架，目标是让模型自己当好 agent，而不是让框架替模型编排。
