AgentScope 2.0 · 架构精读

阿里通义出的通用多智能体框架。本篇按源码解剖它的「重量分布」，并与 InternAgent 做同层对照。

版本 2.0.4.post1（2026-07）· 规模 333 个 .py / ~7.6 万行· 定位 横向对比 / 可以比较的系统

§在科研 agent 谱系里的位置

本系列讲过三种「科研 agent 怎么搭」的路线，AgentScope 是第二种——把重量全压在单 agent 的深 ReAct loop 上，编排层(④)和演化层(⑤)几乎没有。

项目底座选择解耦哲学"做实验"怎么落地
EvoScientist建在 deepagents / LangChain 上一切皆中间件 + YAML 子 agent子 agent 写代码,靠 langgraph 异步底座
AgentScope 👈自造内核(强单体 ReAct)组件注入 + hook由用户在内核上自写
InternAgent完全自造(MAS + 流水线,零 LangChain)状态机 + 工厂注册表:agent / model / tool / 后端各有注册点外包给独立后端:shell 调 claude CLI / iflow / openhands,带自动调试循环
★ 关键对照：同样 6 层，重量分布相反 InternAgent 故意把"单个 agent"做成一次性专员(11 个 agent 仅 generation 用 ReAct 工具循环),把多步思考上移到 ④ 编排层。
AgentScope 正相反——它把重量全压在 ②③(单 agent 深 ReAct loop)，④⑤ 几乎没有。具体说：AgentScope 的 Agent 类内部就是一个 while cur_iter < max_iters 的 reasoning→acting 循环，每轮都能调工具、看结果、再推理；它不提供 InternAgent 那种"11 个专职 agent 按状态机串起来"的编排原语。

本精读分四部分

① ReAct loop（循环骨架、四类 Block、顺序/并发工具批）

② 模块解剖（地图 / 中间件 / 权限 / 工具 / 工作区 / 服务层）

③ 与 InternAgent 的重量对照（6 层套娃表 + 功能维度对照表）

④ 一句话结论（内核极薄、能力域极厚）
