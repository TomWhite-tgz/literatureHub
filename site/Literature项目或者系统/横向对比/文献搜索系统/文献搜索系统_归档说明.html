文献搜索系统归档说明

归档日期：2026-07-31（2026-08-02 深读后更新分类并完成归档）

本批材料都直接研究“如何更全面、准确、可控地搜索学术论文”，应归入文献搜索系统/算法，而不是以文献问答或综述生成为主要目标的系统。

深读结论与归档位置（2026-08-02）

四篇均经论文全文 + 代码深读审稿，详细证据见各项目文件夹内的 深读评价.md。

工作 归档位置 分类 一句话定性
PaSa ../../复杂/PaSa/ 复杂 真 RL 训练 + 真算法贡献（session 级 PPO）+ 权重数据全开放；但部署是硬编码流水线、benchmark 有 citation 可达偏置，SOTA 打七折看
PaperScout ../../简单/PaperScout/ 简单 真做了训练，但 PSPO 实为 GSPO 损失 + turn 级 GAE 的重命名（训练脚本 loss_mode=gspo，论文式(5)与实现不符）；复现性为零
PaperPilot ../../包装的好看/PaperPilot/ 包装的好看 工程外壳真实（DAG 执行器 + 结构化编辑 ~5k 行成立），但"归纳"=抄 36 份手调模板、"偏好优化训练"代码 0 行、主表两行外置覆盖 + 旗舰行硬编码（99.5% forced finalize 未披露）+ 成本 19 倍改写
PaSaMaster ../../包装的好看/PaSaMaster/ 包装的好看 零代码产品广告论文：11 个公式无一承载算法创新，"自演化"实测增益仅 +13%，benchmark 用自家引擎构建（循环性），蹭名 PaSa 却不与 PaSa 比较，语料规模自相矛盾（1.7B vs 160M）

共性问题：① 全部使用自建/自选 benchmark 且有不同程度循环性；② "agent 自主性"普遍是叙事而非实现；③ 后三篇活在 PaSa 的评测生态里但无一与 PaSa 公平正面比较；④ 开放度与论文质量正相关（PaSa > PaperScout > PaperPilot > PaSaMaster）。

1. PaSa

  • 论文：PaSa: An LLM Agent for Comprehensive Academic Paper Search
  • 版本：arXiv:2501.10120v2；ACL 2025 Main
  • 定位：文献搜索 Agent 系统 + Agent 强化学习方法
  • 核心：Crawler 负责搜索、阅读和沿引用扩展；Selector 负责逐篇判断相关性。系统使用 AutoScholarQuery 进行训练，并以 RealScholarQuery 等数据评测。
  • 本地材料：../../复杂/PaSa/（PDF、code、深读评价.md）
  • 官方来源：
  • https://arxiv.org/abs/2501.10120v2
  • https://aclanthology.org/2025.acl-long.572/
  • https://github.com/bytedance/pasa
  • 开放情况：代码仓库采用 Apache-2.0；模型权重和数据集由仓库另行链接，未在本批归档中下载大体积权重。

2. PaSaMaster

  • 论文：Towards Recursive Self-Evolving Agentic Literature Retrieval
  • 版本：arXiv:2605.14306v3
  • 定位：文献检索系统 + 递归自演化检索/排序方法 + PaSaMaster-Bench
  • 核心：根据已检索和排序的证据反复细化搜索意图；只对真实检索到的论文评分，避免生成虚假引用；将高成本意图规划和较轻量的检索、评分分离。
  • 本地材料：../../包装的好看/PaSaMaster/（PDF、code、深读评价.md）
  • 官方来源：
  • https://arxiv.org/abs/2605.14306v3
  • https://github.com/sjtu-sai-agents/PaSaMaster
  • https://huggingface.co/datasets/PaSaMaster/PaSaMaster_bench
  • 开放情况：当前 GitHub 仓库主要是说明文档和图片，不含论文系统的完整实现；可通过在线服务以及 scimaster-cli/MCP 使用。

3. PaperPilot

  • 论文：Multi-Turn Agentic Scientific Literature Search via Workflow Induction
  • 版本：arXiv:2607.00597v2
  • 定位：多轮交互式文献搜索系统 + 工作流归纳与偏好优化方法
  • 核心：从锚点论文和用户查询生成一个可执行、可检查、可编辑的 DAG；节点包含关键词搜索、引用扩展、过滤、打分、重排和证据抽取。用户反馈同时修改查询和工作流。
  • 本地材料：../../包装的好看/PaperPilot/（PDF、code、深读评价.md）
  • 官方来源：
  • https://arxiv.org/abs/2607.00597v2
  • https://github.com/mtilyxuegao/PaperPilot
  • https://paperpilot.papersearch.org/
  • 开放情况：当前仓库采用 Apache-2.0，包含核心系统、API、UI 和部分评测代码；训练基础设施、完整轨迹数据等尚未随首个版本公开。

4. PaperScout

  • 论文：PaperScout: An Autonomous Agent for Academic Paper Search with Process-Aware Sequence-Level Policy Optimization
  • 版本：arXiv:2601.10029v2
  • 定位：自主文献搜索系统 + PSPO 强化学习算法
  • 核心：把检索建模为 POMDP，让 Agent 根据当前论文池自主决定何时搜索、使用什么查询、何时沿引用扩展；PSPO 在完整 Agent 响应/交互序列层面分配信用，并结合过程奖励。
  • 本地材料：../../简单/PaperScout/（PDF、code、深读评价.md）
  • 官方来源：
  • https://arxiv.org/abs/2601.10029v2
  • https://github.com/pty12345/PaperScout
  • 开放情况：官方仓库包含 PaperScout/PSPO 训练相关代码，但仓库根目录目前没有单独的 LICENSE 文件，应谨慎理解其复用许可。

横向定位

工作 主要搜索范式 最突出的创新 用户交互 主要产物
PaSa 搜索 + 引用网络扩展 + 相关性筛选 双 Agent 与 RL 训练 单轮复杂查询为主 排序/筛选后的相关论文集合
PaSaMaster 证据驱动的递归自演化检索 意图随证据迭代、真实来源排序、规划/检索分离 以递归内部迭代为主 有证据和分数的真实论文集合
PaperPilot 多轮对话 + 可执行 DAG 工作流归纳、用户反馈直接编辑工作流 强，多轮澄清偏好 可复现工作流及排序结果
PaperScout 自适应 Search/Expand 决策 POMDP 建模与 PSPO 序列级强化学习 主要是 Agent 与检索环境多轮交互 高召回论文集合及自适应策略

它们与 OpenScholar、PaperQA 一类“检索后回答/综述综合”系统的边界是：本批工作的第一目标是把正确且较完整的论文集合找出来；回答生成、长篇综述或跨论文知识综合不是主要终点。
