几个LabBench2的问题：
- 评价最终答案，不评价过程
- 不是完整的“Ai Scientist”测试，而是一组科研Agent的原子能力测试
- 全量运行成本较高：1912次被测系统执行、1498次Judge调用
- 数据源漂移问题

大概的介绍

  • LitQA3、PatentQA、TrialQA、SuppQA2：论文、专利、临床试验和补充材料检索。
  • FigQA2、TableQA2：视觉或文档 QA
  • SourceQuality：系统综述中的研究适用性与排除理由判断。
  • ProtocolQA2：实验故障诊断 QA
  • DbQA2：数据库查询结果生成
  • SeqQA2：要求计算并输出序列、引物或数值
  • Cloning：要求生成满足约束的克隆方案，并由程序验证

关于 LabBench2

LitQA3:只给模型一个具体的生物医学问题，让它自己找到对应论文、阅读全文并返回简短答案。

  • 168道开放问答题
  • 166 道对应一个来源，2 道对应两个来源
  • 每道都有人工保存的关键证据段落。
  • 标准答案非常短，中位数只有一个英文单词；最长的答案也只有8个单词
  • 两个环境：Base / Tool-augmented, high-effort
  • （me）：没有统一工具？OpenAI Responses 用web_search、code_interpreter；Anthropic API用web_search、web_fetch、code_execution
  • 是一个“开放式文献检索 QA”，不是给定论文后的阅读理解。
  • 数据集内部有来源DOI、关键证据段落，但是实际评测的时候，被测模型实际只收到上面的英文问题
  • 例子：
  • 某种细菌经过实验室进化后，对哪种抗生素产生抗性？（A：ciprofloxacin）
  • 小鼠嗅觉神经元中，活跃嗅觉受体基因与 Greek Island 区域的接触增加了多少倍？(A: 2.7 fold)

PatentQA：检索目标从论文变成了完整专利（只给 Agent 一个问题，让它自己搜索、识别并阅读对应专利，然后回答其中的具体技术信息）

  • 121道题目
  • 每个题目对应一个Google Patents来源，有人工保存的关键证据段落，来源均为 patents.google.com
  • 答案中位数1个英文单词、平均3.3个，最长29个
  • 用语义LLM Jduge评分
  • 例子
  • 在专利 CA2825940C 描述的稳定生物油项目中，什么成分阈值被用来定义可直接作为燃料的热稳定生物油？

TrialQA：只给 Agent 一段关于某项临床试验的问题，让它自行识别对应试验、找到 ClinicalTrials.gov 页面，并提取特定事实。

  • 和 LitQA3、PatentQA 属于同一类开放检索任务:
  • LitQA3: 检索论文
  • PatentQA: 检索专利
  • TrialQA: 检索临床试验注册记录
  • 120道开放式问题，覆盖102个不同的临床试验
  • 全部来源于 ClinicalTrials.gov
  • 例子
  • In the MK-2118-001 trial, what is the minimum number of weeks participants must have HIV RNA below 50 copies/mL, and the minimum number of weeks they must be on a stable drug/dose regimen before study entry?(Ans:12,4)

FigQA2 & TableQA2

  • 都有三种变体：只有问题/问题+裁剪后的图或图片/问题＋完整论文
  • 每个图或表周围构造三个变体任务，而不是把一个问题机械复制三遍

ProtocolQA2 (给 Agent 一份被人为篡改过的实验 Protocol PDF，并描述执行后出现的失败现象，要求找出其中唯一重要的错误。)

  • 125道开放式问题，115来自公开的Protocol、10题来自专家提交的未公开Protocol
  • Agent收到 问题+被修改过的Protocal PDF+固定的回答要求
  • 题目构造的方式：
  • 领域专家先取得一份正常实验方案，然后故意引入一个会导致明确失败的错误（把37°C改成100°C...）
  • 随后根据这个错误构造一个实验失败场景，让模型反向诊断
  • 例子：第3天结束时加入 GlycoBlue 后没有出现蓝色 RNA 沉淀，可能是什么原因？（第3天第29步应该取水相，但实验中取了有机相。）
  • 每份 Protocol 已知只注入了一个明确错误。

DbQA2 : 给 Agent 一个需要查询专业生物数据库的问题，让它找到正确记录、下载或解析数据，并返回精确结果。

  • 包含 86 道开放式问题，覆盖43个生命科学数据库，每个数据库2道题目
  • 这些数据库是通过分析约1000篇近期 bioRxiv 论文中的数据来源，再结合生物学专家意见选出来的。
  • 例子：
  • 收到问题：What is the human genome reference sequence from region chr14:89000000-89000100 in hg38?
  • 标准答案："reference_sequence": "ATCTTGTCACTATGGTGGGGGAGCTTGGAGCAGCTGGGACCACTGTGGGAAGCATGAGGGTGAAGCCAACATGGTGGAAAGCAGATCTAAATCTGGAGAGA"

SeqQA2： 给模型生物序列或实验数据，要求进行精确计算、序列操作或分子设计，再用程序验证答案。

  • 400道题目，20种子任务，442个附件

CloningQA：要求模型设计并输出一套能被计算机执行的完整DNA组装方案

  • 14个场景
  • 例子：
  • Gibson：替换载体中的基因。 使用 pLVX-EGFP-IRES-puro 作为载体，以小鼠 Sorcs2 为插入片段，用 Sorcs2 替换 EGFP，设计 Gibson Assembly。

SuppQA2 : 从论文补充材料里找一个精确事实

  • 125道开放式问题、对应119篇不同论文

SourceQuality：给 Agent 一篇已知被系统综述排除的论文，以及系统综述的具体研究问题，要求解释为什么这篇论文不能提供合适证据。

  • 150道题、每题提供paper.pdf，对应25个不同的综述
  • Agent收到一个具体的证据医学研究问题+paper.pdf+明确告知这篇研究被专家排除了， 要求说明排除原因
  • 例子：专家认为 paper.pdf 不能用于回答：对于急性细菌性结膜炎患者，抗生素治疗与安慰剂相比是否改善临床和微生物学治愈率？为什么排除该研究？(该研究没有安慰剂对照，只比较了不同的主动治疗。)
