XYZ-Aquila SFT

XYZ-Aquila SFT is a bilingual release of 7,000 multi-turn, search-oriented
tool-use trajectories, comprising 5,000 English examples and 2,000 Chinese
examples.

This release is a sample of the broader supervised fine-tuning data used for
XYZ-Aquila-mini and
XYZ-Aquila-pro. The examples
capture agent interactions with search tools, intermediate observations, and
answer generation in English and Chinese.

A small portion of the QA content is derived from
PolarSeeker/OpenSeeker-v1-Data.

The final XYZ-Aquila models trained with the broader SFT corpus demonstrate
strong performance across English and Chinese agentic-search benchmarks.

Data Format

Each line is a JSON object with four top-level fields:

{
  "question": "<user request>",
  "answer": "<final answer>",
  "number of tool calls": 3,
  "trajectory": [
    {"role": "system", "content": "<system instruction>\n\n# Tools\n\n...\n<tools>\n...\n</tools>\n..."},
    {"role": "user", "content": "<user request>"},
    {"role": "assistant", "content": "<reasoning and tool call>"},
    {"role": "user", "content": "<tool response>"},
    {"role": "assistant", "content": "<final response>"}
  ]
}
Field Type Description
question string User request associated with the trajectory.
answer string Final answer supervision.
number of tool calls integer Number of tool invocations represented in the trajectory.
trajectory list Ordered system, user, and assistant messages, including tool interactions.

Tool definitions are rendered into the first system message using the tools
block from the official Qwen3 chat template. Tool invocations and observations
are serialized inside assistant and user message content, preserving the full
multi-turn interaction in a self-contained chat structure.

Qwen3 Tools and Conversion

The public JSONL is designed to remain usable even when a consumer does not
pass a separate tools argument to a chat template. Each first system message
therefore includes the three function schemas used by the trajectory:
web_search, scrape_and_extract_info, and run_python_code.

The embedded block is byte-equivalent to the system-message content produced
by the official Qwen3 chat template when it receives the original system
message and the structured tools list.

Choose one of the following paths to avoid injecting the schemas twice:

  • Message-only path: use trajectory as published and do not pass a
    separate tools argument when applying a chat template.
  • Structured-tools path: first run
    convert_tools.py in extract mode. This restores the
    original system message and adds a top-level structured tools list, which
    can then be passed to a Qwen3-compatible chat template.

Extract a structured tools list:

python convert_tools.py extract \
  --input xyz_aquila_sft_en_5000.jsonl \
  --output xyz_aquila_sft_en_5000_structured_tools.jsonl

For pipelines that require the tools list as a JSON-encoded string, add
--tools-format string. The script also provides the inverse operation for
reproducibility:

python convert_tools.py render \
  --input xyz_aquila_sft_en_5000_structured_tools.jsonl \
  --output xyz_aquila_sft_en_5000_rendered_tools.jsonl

extract followed by render reproduces the published records exactly. A
runtime option such as --tool-call-parser qwen3_coder remains an inference
deployment setting; the converter changes only where function schemas are
stored and does not rewrite assistant tool calls or tool responses.

Loading the Dataset

Load one language configuration with 🤗 Datasets:

from datasets import load_dataset

english = load_dataset(
    "XYZAILab/XYZ-Aquila-SFT",
    "en",
    split="train",
)

chinese = load_dataset(
    "XYZAILab/XYZ-Aquila-SFT",
    "zh",
    split="train",
)

Streaming is also supported:

english_stream = load_dataset(
    "XYZAILab/XYZ-Aquila-SFT",
    "en",
    split="train",
    streaming=True,
)

Intended Uses

The dataset is intended for research and development involving:

  • supervised fine-tuning of search-oriented agents;
  • bilingual tool-use and multi-turn reasoning;
  • trajectory-format experimentation and agent behavior analysis;
  • controlled studies of English and Chinese search tasks.

Related Models

The broader SFT corpus containing this data was used in the development of:

  • XYZ-Aquila-mini
  • XYZ-Aquila-pro

Model evaluation results and model-specific usage guidance are provided on the
respective model pages.

Limitations

  • Search-derived information can become outdated, incomplete, or inconsistent
    with current sources.
  • Tool schemas and trajectory conventions may require adaptation for other
    agent frameworks.
  • The dataset is not an independent benchmark, and training on it does not by
    itself establish factual reliability or deployment readiness.
  • Users should independently verify generated answers and evaluate models for
    their intended domains, languages, and risk requirements.
