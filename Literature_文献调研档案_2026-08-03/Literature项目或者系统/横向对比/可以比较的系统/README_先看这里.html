可以比较的系统

这里放置处于相近抽象层、能够进行相对公平横向比较的 Agent 系统。

当前收录：

  • AgentScope：完整 Agent 应用框架，包含 Agent 运行循环、模型与工具接入、状态/记忆、权限、事件、工作区及服务化能力。

收录标准

优先收录能够直接承担 Agent 应用开发与运行控制的完整框架，例如：

  • 自身具有 Agent reasoning–acting loop；
  • 负责模型、工具和上下文/状态管理；
  • 能运行面向用户的完整任务；
  • 具有一定的可观测、权限、会话或部署能力。

LDP 侧重 policy、rollout、trajectory 与训练优化；AgentENV 侧重 microVM sandbox 基础设施。它们与 AgentScope 所在层次不同，因此不放入这一组直接比较。
